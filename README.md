# Campus Hackathon Manager

A premium MERN SaaS dashboard for campus hackathon operations: student registration, teams, mentors, judges, admin analytics, AI workflows, QR attendance, chat, certificates, and project submissions.

## Run

```bash
npm install
npm run dev
```

Frontend: `http://localhost:5173`  
Backend: `http://localhost:5000`
